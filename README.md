# ClientHub - CRM Web Application Demo

## 📝 概要 (Overview)

モダンなWeb技術を用いて構築された、顧客関係管理（CRM: Customer Relationship Management）システムのデモンストレーションアプリケーションです。

UI/UXの確認や機能テストを目的としており、あらかじめ用意されたモックアップの顧客データ（架空の顧客レコード）が組み込まれています。

**🌐 Live Demo**: [https://crm-system-ico.vercel.app/](https://crm-system-ico.vercel.app/)

## ✨ 特徴 (Features)

- **顧客データ管理**  
  顧客情報のリスト表示、詳細確認などの基本的なCRMインターフェースを提供

- **モックデータによる即時プレビュー**  
  ダミーの顧客レコードが初期ロードされるため、データベースのセットアップなしですぐにシステムの挙動を体験可能

- **高速・軽量なUI**  
  状態管理ライブラリを活用し、ページ遷移やデータのフィルタリングにおいてシームレスで高速なユーザー体験を実現

## 🛠 技術スタック (Tech Stack)

| カテゴリ | 技術 |
|---------|------|
| **Framework** | Next.js / React |
| **Styling** | Tailwind CSS |
| **State Management** | Zustand |
| **Deployment** | Vercel |

## 📂 主な機能想定 (Core Modules)

- ダッシュボード（KPI、顧客のサマリー表示）
- 顧客一覧・検索・フィルタリング
- 顧客詳細情報の閲覧

本アプリケーションはデモンストレーション目的で公開されています。システム内に登録・表示されている顧客データはすべて架空のモックデータであり、実在の個人や企業とは一切関係ありません。
